Why This Toolkit

Figma

Figma is where every project actually starts, structure, flows, and UI decisions, before anything else. It's the primary tool I use to communicate and align with clients and teams.

React and Next.js

When a project calls for it, component-based architecture maps directly onto how I already think about interfaces, which makes design-to-code feel like a continuation of the same thinking, not a handoff to someone else.

Claude Code and Cursor

I use AI to move faster through prototyping, iteration, and, on select projects, implementation, so more of my time stays on product decisions instead of mechanical work.

Supabase and Deployment

Lightweight backend tools and simple deployment let me take a design past the mockup stage when a client needs to see and use the real thing, not just review it.
