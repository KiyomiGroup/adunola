Project Overview

ScrumConsult needed a digital product to support agile and scrum-based workflows. I was responsible for designing the entire user experience and interface for both the website and mobile versions from scratch, including the product structure, user flows, and visual system, before any development began.

The project was paused midway after the client decided to stop work. It wasn't fully built out as a result, but the design work produced stands on its own as a complete UX process for a B2B SaaS-style product.

"With no existing product foundation to build on, the job was to invent the structure, not just decorate it."

Problem Statement

The client needed a modern, intuitive platform that:

  • Clearly communicated the product's value proposition to a B2B audience
  • Worked seamlessly across desktop and mobile devices
  • Balanced professional B2B usability with a clean, engaging interface

There was no existing design system or product foundation to inherit, so the project required a full design build from zero.

My Workflow & Approach

1. Discovery & UX Planning

Clarified product goals, target users, and core features, then defined information architecture and the primary user flows before any screens were drawn.

2. Wireframing & Structure

Created low-to-mid fidelity wireframes for key pages, focused on clarity, simplicity, and logical navigation for a B2B audience with no patience for confusion.

3. UI Design & Visual System

  • Designed high-fidelity web and mobile screens
  • Established consistent typography, spacing, and component styles
  • Ensured visual hierarchy and accessibility across devices

4. Mobile-First & Responsiveness

Designed mobile layouts alongside desktop versions in parallel, optimizing touch interactions and content prioritization for smaller screens rather than treating mobile as an afterthought.

Where the Project Stands

Paused after the client stopped development mid-project
A cohesive web and mobile design system, from wireframe to high-fidelity UI
Full IA and user flows defined before any UI work began
Owning a product design from concept to execution, even under external constraints

What I Learned

Working from zero — no existing brand, no prior product, no legacy patterns to inherit — forces a different kind of discipline than redesign work. Every structural decision has to be justified on its own, because there's nothing to fall back on.

The project also reinforced how much early UX planning protects a product's clarity later. Even paused, the IA and flows I defined at the start are still coherent enough to hand to another team without confusion.
