Project Overview

Retro is a self-initiated concept for a crypto asset management platform, exploring how someone might track profits, losses, real-time market movement, and wallet activity in one unified dashboard. It's not a client project or a shipped product — it's an exploration I designed to work through a hard information-density problem: making a lot of financial data feel calm instead of overwhelming.

"Crypto investors juggle market data on one app, wallet activity on another, and portfolio insight on a third. Retro asks what happens if that's one screen."

The Problem I Explored

Crypto investors often deal with information scattered across tools — pricing on one app, transactions on another, portfolio performance somewhere else entirely. That fragmentation slows decisions and adds friction right when clarity matters most.

The goal for Retro was to design a centralized space where someone can see the essential financial metrics at a glance, aimed at both beginners and experienced traders.

Design Approach

  • Developed the flow as wireframes → high-fidelity screens → prototype, to keep consistency across every page
  • Used neon highlights, smooth curves, and minimalist typography for aesthetic cohesion suited to a financial product
  • Built a data-centric layout using charts, graphs, and cards to communicate complex information without clutter
  • Designed the system to stay scalable for future features like AI-driven insights and automated analytics

Key Screens Designed

  • Unified Dashboard — portfolio value, performance graphs, and asset allocation visuals
  • Market Overview — pricing trends across multiple cryptocurrencies
  • Transaction Manager — a clean activity log with real-time status indicators and quick actions
  • Wallet Integration — a smooth connection flow to a user's preferred crypto wallets
  • Profile & Settings — optimized for quick customization
  • Dark Theme UI — reduces eye strain and reinforces a modern, technical brand identity

What This Exploration Shows

Concept — not a client engagement or a shipped product
Reduce confusion around multi-asset tracking; make crypto data legible for beginners
A cohesive dark-theme UI kit built for data-dense financial screens
Information hierarchy and dashboard design under real data density

Design Reasoning Notes

Dashboards are one of the harder UI problems because the temptation is always to show more. Every screen in Retro started from the opposite question: what's the single number or chart this user needs first, and what can wait one tap away. That discipline is what actually makes a "premium" financial UI feel premium — restraint, not decoration.
